# Quiz-pakker vælges med stien i stedet for ?quiz=

> Status: in progress — claude/dazzling-mccarthy-20g9n0

## Goal

A pack is opened at `/julequiz/<pack>` (e.g. `/julequiz/jul-2025`) instead of
`/julequiz/?quiz=<pack>`. Every pack is prerendered as its own static page, so it works on GitHub
Pages without a server. The bare root `/julequiz/` keeps showing `DEFAULT_QUIZ`, and an unknown path
shows Waku's static 404 page with "Ukendt quiz: <navn>" and links to every pack.

## Out of scope

- Redirecting or reading old `?quiz=` links. The query string is simply no longer read.
- Prerendering the board itself (it still renders after mount, see Decisions).
- Per-pack `<title>`, OG tags or `og:url`. `_layout.tsx` and `SITE_URL` stay untouched.
- Waku `<Link>` / client-side navigation between packs.
- Validating pack names against reserved folder names in code (documentation only).
- Any change to `quizState.ts` storage keys, `SettingsMenu`, `ResetQuizSetting` or the board UI.

## Decisions made

- Root `/julequiz/` → renders `DEFAULT_QUIZ` (`jul-2025`) exactly as today, no redirect. It shares
  saved state with `/julequiz/jul-2025` (state is keyed by pack name).
- Old `/julequiz/?quiz=<name>` → ignored; the root shows the default pack.
- Unknown path (e.g. `/julequiz/nope`) → static `404.html`; after mount it reads the pathname and
  shows "Ukendt quiz: nope", "Vælg en quiz:" and a list of links to `/julequiz/<pack>`.
- The pack page still renders the plain `bg-night` placeholder until mount and only then the board
  (same first paint as today). Prerendered board HTML would show doors in file order at scale 1
  before shuffle, saved state and `Stage` scaling kick in.
- Pack links have no trailing slash: `/julequiz/jul-2025`.

## Architecture facts (verified)

- Today `src/pages/index.tsx` is one `"use client"` file: helpers `shuffleQuestions`, `gridColumns`,
  `tickGroup`, the `QuizBoard` component (`{ quiz: LoadedQuiz }`) and default export `HomePage`
  (lines ~448-481), which reads `?quiz=` in an effect, shows `<div className="bg-night h-screen" />`
  until then, renders the unknown-pack list, or `<QuizBoard key={packName} quiz={quiz} />`.
- `QUIZZES` (`Map<string, LoadedQuiz>`) in `src/quizzes/index.ts` eagerly imports every pack, its
  questions and renderers. Its comment at line 60 mentions `?quiz=constructor`.
- `DEFAULT_QUIZ` and `SITE_URL` live in `src/config.ts`. `asset()` in `src/asset.ts` prefixes
  `import.meta.env.BASE_URL` (`/julequiz/`) and strips the argument's leading `/`.
- `src/pages/_root.tsx` shows the server `getConfig` pattern (`render: "static"`).
- Prototyped during planning (Waku 0.27.4) and confirmed working:
  - `src/pages/[quiz]/index.tsx` as an async server component with
    `export default async function QuizRoute({ quiz }: PageProps<"/[quiz]">)` and
    `getConfig` returning `{ render: "static", staticPaths } as const` builds
    `dist/public/jul-2025/index.html` and `dist/public/RSC/R/jul-2025.txt`.
  - `staticPaths` from a **non-eager** glob in that file works in build and dev:
    `Object.keys(import.meta.glob("../../quizzes/*/quiz.ts"))` gives keys like
    `"../../quizzes/jul-2025/quiz.ts"`; extract the name with `/\/quizzes\/([^/]+)\/quiz\.ts$/`.
  - `src/pages/404.tsx` with static `getConfig` builds `dist/public/404.html`. GitHub Pages serves
    it for every missing path; `npm start` serves it with status 404 for `/julequiz/nope`.
  - GitHub Pages and `npm start` both serve `/julequiz/jul-2025` and `/julequiz/jul-2025/`.
    **`npm run dev` returns 500 for `/julequiz/jul-2025/` (trailing slash)**; without the slash it
    is 200.
  - `src/pages.gen.ts` is regenerated by `npm run dev`, not by `waku build`. After dev it lists
    `/404` and `/[quiz]`. `tsc` passes either way.

## Traps

- **Do not read `window.location` (or `localStorage`) during render or in a `useState` initializer.**
  Every page is prerendered; the first client render must match the HTML or hydration breaks.
  Read the pathname only in `UnknownPack`'s effect, and keep `QuizPage`'s mount gate.
- **Do not import `QUIZZES` (or `src/quizzes/index.ts`) from a server file.** It eagerly imports
  every question spec and renderer; in the RSC environment that drags client modules and `toQuestion`
  JSX into the server build. The server page gets names from the non-eager glob, and only client
  components touch `QUIZZES`.
- **Do not pass a `LoadedQuiz` from a server page to a client component.** Questions hold JSX and
  functions that cannot cross the RSC boundary. Pass the pack `name` string only.
- **Do not use the eager glob or `{ eager: true }` for `staticPaths`.** Same reason as above; the
  keys alone are enough.
- **Do not put a trailing slash in pack links** (`asset(`/${pack}/`)`). `npm run dev` answers 500
  for it. Pages redirects the slash-less form itself.
- **Do not use Waku's `<Link>` for pack links.** Client navigation would keep the old board's
  sounds and state alive; a plain `<a>` gives a fresh page load.
- **Do not write `/julequiz/…` by hand or call `asset()` twice.** Use `asset(`/${pack}`)` once, and
  `import.meta.env.BASE_URL` for the prefix in `UnknownPack`.
- **Do not name the page `src/pages/[quiz].tsx`.** Only `[quiz]/index.tsx` was verified to emit
  `jul-2025/index.html`.
- **Do not edit `src/pages.gen.ts` by hand.** Let `npm run dev` regenerate it (step 8).
- **Do not "improve" `QuizBoard` while moving it.** Keep the `isLoaded` gate, the `sway={false}`
  comment, the snow z-index comment and everything else byte-identical apart from imports. `key`
  on `QuizBoard` is no longer needed, since `QuizPage` mounts it once per page load.
- **Do not use `undefined` for optional props** (`exactOptionalPropertyTypes`); omit them.
- Comments must ADD value: only a non-obvious constraint, invariant, why, or corner case. Never
  explain what the code does. New comments (Danish, one line each) only at: `QuizPage`'s mount gate
  (prerendered board would show doors in file order at scale 1 before shuffle/saved state/scaling),
  and the non-eager glob in `[quiz]/index.tsx` (the eager `QUIZZES` must not reach the server).
  Everything else needs none. Keep all moved comments.
